# UI 改版说明：苹果照片风格

设计稿（Design 画布，8 个页面）：https://claude.ai/artifact/HywA5V3m7ds5S6raVJh2af
画布里每个页面是 `project/<名字>.dc.html`（Main / Calendar / Grid / Detail / Editor / Review / Tags / Search），用 artifact 工具的 read_file 可以读到源码，里面的尺寸、字号、颜色就是准确值。稿里的照片是从 README 截图裁的，模糊是素材问题。

## 原则

颜色交给照片，控件是玻璃、退后一层。能用画面说明的，就不写文字说明。

- **不加多余的说明文字。** 图标、照片、示例、控件本身的状态能讲清楚的，就不再写一行解释：空状态只有一句标题（最多一个动作按钮），不写“在这里会出现什么”；分组标题下不加副标题；设置的 footer 只留画面表达不了的事实（例如“删除 App 不会丢失日记”）。确认删除、写入失败这类后果说明可以保留。新增文字前先问：去掉它，用户会不会做错？不会就不加。

- 去掉所有主题色导航栏和色块头部（`toolbarBackground(brand)`、`toolbarColorScheme(.dark)`、JournalView 的主题色背景、白色圆角卡片上沿）。背景用 `systemBackground`，滚动时靠系统的 scroll edge 效果。
- 主题色（`\.brand`）只用于：标签文字、"+"按钮、"追加感想"按钮、选中态、今天的日期圆。新增 `brand.opacity(0.1)` 作为标签胶囊底色。
- 导航按钮用 iOS 26 默认的玻璃圆钮（图标，不用"编辑""完成"文字）。
- 界面字体 SF；日记正文继续用宋体（`Font.diary`），不变。
- 不改动：`Library/`、`Model/`、说明格式、同步逻辑。只改 `Views/` 和 `Design/`。

## 全局 / RootView

- 底栏保持现在的结构：玻璃胶囊［日记 · 回顾 · 搜索］+ 右侧 62pt 主题色"+"圆钮。（刻意没学照片 App 把搜索拆出去，"+"是主要操作。）
- 日记标签页在根页面时，标签栏上方多一个浮动玻璃分段控件：列表 / 日历 / 照片 / 地图，高 40、胶囊形、每段约 58pt 宽，选中段 `primary.opacity(0.075)` 底 + semibold，取代 JournalView 顶部的 ModeSwitcher。

- 头部：系统大标题"日记"，下面一行副标题"十月写了 12 篇"（15pt，secondary），右上角玻璃圆钮 ⋯ 菜单（标签、设置）。不再有主题色背景。
- **列表 → 大照片卡片**（新组件 `EntryCard`，替换 `EntryRow` 在列表里的用法；搜索结果、某一天列表可继续用紧凑的 `EntryRow`）：

  - 照片下 12pt：元信息行"周五 · 10月30日 · 杉并区"（13pt semibold secondary）→ 标题 `diary(20, bold)` → 预览 `diary(15.5)` 次要色、行距大、最多 3 行 → 标签（13pt semibold 主题色）。
  - 卡片之间 30pt。
- 那年今日横幅：灰底圆角 18 的小卡片（48pt 缩略图 + "1 年前的今天"主题色 + 宋体一行 + chevron）。
- 月份标题：22pt bold "10月" + 15pt 次要色年份 + 右侧"10 篇"。
- **日历**：去掉白卡片；星期行吸顶，下方细分隔线；格子间距 2、左右边距 4、圆角 8；有日记的日子铺照片、日期白字在左上角；没日记的日子 17pt 普通字；今天是 34pt 主题色实心圆、白字。

## 详情（EntryDetailView）

- 照片顶到屏幕最上（ignoresSafeArea top），横图高约 312，竖图沿用现在的比例规则；导航栏透明，返回、编辑（铅笔）、⋯ 是浮在照片上的玻璃按钮，编辑和 ⋯ 合在一个胶囊里。往上滚过照片后再显示日期标题。
- 正文：元信息行"2023年10月31日 周二 · 3 年前"（13pt semibold secondary）→ 标题 `diary(24, bold)` → 正文 `diary(18)` 次要色；段落分隔线保持现状。
- 地点和标签从底部浮条移到正文末尾，做成高 34 的胶囊：地点 = 灰底 + mappin 图标；标签 = 主题色 10% 底 + 主题色字。
- 底部：左边 52pt 玻璃圆钮"分享"，右边主题色胶囊"+ 追加感想"。
- 深色模式下背景纯黑。

## 编辑器（EditorView）

- 整页是一张翻过来的相纸，放在深一层的暖灰桌面上（深色模式桌面是黑）。字写在照片背面，本来就是人们记照片日记的方式（`PhotoPaper`）：
  - 纸：这张照片左右镜像铺满，降饱和、压对比、提亮成中间调，虚化 2.5pt，再盖 85% 的纸色（深色模式是 86% 的深灰）——正面的影子隔着纸隐约透过来，暗的照片也不会把纸染灰。
  - 纸面有随机灰噪点的细颗粒（叠加混合），和相纸背面那种一排排斜印的淡淡厂标：这里是 App 自己的拍立得图形，12pt 宽、76pt 一格、隔行错开、4% 不透明度。
  - 纸到屏幕边缘 14pt，圆角 6，0.5pt 白色高光描边，两层投影；纸内文字边距 22pt。键盘弹出时纸随之变矮，像一张横放的 4×6 照片。
  - 纸上的内容从上到下：以前写的字（标题……最后一段，宋体 16、次要色、最多四行）→ “今天 · 11月1日”分隔线 → 正在写的字。不再放原照片的缩略图卡片：纸背透出来的影子就是这张照片。
- 去掉主题色导航栏。左上 ✕（取消），右上 ✓（主题色 glassProminent），中间两行：日期 + "追加感想 / 写日记 / 编辑"（12pt secondary）。
- 键盘上方一条玻璃胶囊工具栏：左边 40pt "#" 圆钮（主题色 10% 底）、中间横向的标签联想胶囊（白底细边、主题色字，输入 # 时显示）、右边收起键盘。去掉现在的竖向弹出列表。

## 回顾（ReviewView）—— 参照照片 App 的"精选集"

- 白底（不再用 grouped 灰底），大标题"回顾"。
- 每组一个 22pt bold 的组标题，可点的组带灰色 chevron（"那年今日 ›"）。
- 那年今日：横向翻页的大卡片 330×420、圆角 26，露出下一张的边缘；底部 62% 黑色渐变，白字："3 年前的今天"、宋体 23 bold 标题、"地点 · 2 段"；右下角玻璃"+"（追加）。下面是页码点。
- 这周写了 N 篇：灰底圆角 22，七列：星期、日期、写过的日子下方主题色小圆点，今天是实心圆。
- 还没写的照片 ›：副标题"趁还记得，写下当时的感受"，横排 150×150 圆角 18 的照片，左上日期、右下玻璃"写"按钮。
- 标签 ›：两列封面网格（前 4 个），封面是最近一篇的照片，圆角 16，下方标签名 + "N 篇"。

## 标签（TagsView）

- 两列相簿式封面网格，下方"#旅行#"和"8 篇 · 最近 10月24日"。

## 搜索（SearchView）

- 大标题"搜索"。输入前显示三组：标签（灰底胶囊，主题色标签名 + 篇数）、地点（140×172 封面卡片，底部渐变压白字地名和篇数）、时间（两列 96pt 高的卡片：那年今日 / 最近 30 天 / 最近一年铺这段时间里的照片、压白字和篇数，几块不用同一张；"选择日期"是灰底加本月的小日历点阵）。
- 分组标题和其他页面的 `SectionTitle` 一样（22pt 半粗）。标签胶囊是主题色 10% 底 + 主题色字 + 篇数，和详情页的标签胶囊一致。
- 选了筛选条件后，顶部一排主题色实心胶囊（高 38）：图标 + 名称 + 右侧一枚 24pt 白色实心圆里的主题色 ✕（独立按钮，一眼看出能去掉）。日期胶囊点一下回到日历改；还没选日期时末尾有一个灰底日历按钮。日期范围写成"10月3日至12日"，今年不写年份。
- 结果按月分组，月份标题和日记页一样。换了筛选条件滚回最顶上（连同大标题；`scrollTo(edge: .top)` 会停在大标题下面，所以往上滚过头让滚动视图自己夹住）。
- 搜索框在底部：左边玻璃圆钮回到日记，右边玻璃胶囊输入框"日记内容、地点、#标签#"。
