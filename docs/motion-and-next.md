# 动效改进和接下来的功能

## 一、动效：原则

参考：Apple HIG〈Motion〉、WWDC18〈Designing Fluid Interfaces〉、WWDC23〈Animate with springs〉、WWDC24 / WWDC26 的 SwiftUI 着色器课程、Emil Kowalski 的“按使用频率决定动不动”。

**1. 先看多常用，再决定动不动。**

| 频率 | 例子 | 做法 |
|---|---|---|
| 一天很多次 | 滚动日记、切换标签栏、点开一篇 | 只用系统动画，不加自定义动效 |
| 一天几次 | 写日记、保存、看大图 | 短（≤ 300ms），可打断，绝不让人等 |
| 偶尔、第一次 | 开屏、第一篇日记、一年回顾 | 可以有记忆点：显影、着色器 |

**2. 动画要跟着手，不是点一下自己播。** 这是“精致感”最大的来源，App 现在完全没有（全工程没有一个 `DragGesture`）。

- 手指一按就有反应；手势要全程追踪，不用只在结束时判断的识别器（`UISwipeGestureRecognizer`）。
- 动画中途可以被新的手势抓住、拉回来。
- 松手时把手指的速度接过去，按惯性会停在哪里来决定去向，而不是看当前停在哪。
- 拖过边界不硬停，带阻尼继续跟手（橡皮筋）。
- 从哪儿来回哪儿去：往下拉出来的，就往上收回去。

**3. 弹簧参数沿用 `Motion.swift`。**

- 默认不回弹（bounce 0）。
- 只有带动量的手势，松手后才给 0.8 阻尼，有一点点回弹。
- 回弹到 0.3 左右才明显，超过 0.4 就太夸张。

**4. 动画不能是唯一的信息。** 状态落定的那一下配触感（`sensoryFeedback`）。

“减少动态效果”时，位移改成淡入淡出，意思不变。

**5. 着色器只用在少见的时刻。** SwiftUI 有三种效果：

- `colorEffect`：改颜色。
- `distortionEffect`：挪像素。
- `layerEffect`：能读周围的像素，最灵活。

着色器没有时间，动画要用 `TimelineView(.animation)` 把时间传进去。

## 二、动效：既有界面怎么改

按值得程度排序。

### 1. 看大图：跟手下拉关闭（`PhotoViewer`）

现在用的是 `UISwipeGestureRecognizer`，手指划完才关闭，中途照片不动。改成：

- 换成 `UIPanGestureRecognizer`，只在没放大、往下拉时生效。
- 拖动时照片跟着手指走、略微缩小（最小 0.8），黑底随距离变透明。
- 松手时按速度推算落点：超过阈值就关闭，zoom 转场把照片缩回详情页原位；不够就弹回原位。弹回用 `.drawer`，带一点回弹。
- 判断的时机：拖动途中只要往回拉，就取消关闭。
- 测试：界面测试里下拉一小段，松手后还在；下拉一大段，关闭。

### 2. 写日记：照片翻到背面（`EditorView`）

编辑器本来就是“翻过来的相纸”，缺的是“翻”这个动作。

- 打开时，先显示照片正面，然后绕 Y 轴翻到纸背（`rotation3DEffect`，0.35 秒，翻到 90° 时换成纸背）。
- 键盘和光标立即可用，不等翻完。
- 取消时往回翻，和打开方向相反。

  可以拖：在纸的上沿往下拖，纸按拖动距离翻回去，松手按速度决定是关闭，还是翻回来继续写。

- “减少动态效果”时只做淡入淡出。
- 这一步要把编辑器从 `.sheet` 改成全屏呈现，翻转才看得见。改之前要确认 iPad 和横屏的布局。

### 3. 保存：墨水落定

- 点 ✓ 后，新写的那段字轻微下沉、变成正文颜色（≤ 250ms）。
- 同时配一次 `.success` 触感，然后关闭。
- 不阻塞：写入照片库和动画同时进行。写入失败时字恢复原样，再弹错误提示。

### 4. 标签建议胶囊

- 出现：从键盘上方的工具栏里淡入，并带轻微缩放，几个胶囊依次出现，间隔 30ms。
- 点一下：胶囊用 `matchedGeometryEffect` 飞进正文末尾，然后消失。
- 一次写作最多出现一次，不算高频。

### 5. 回顾里的“那年今日”卡片

- 横向翻页时，不在中间的卡片略微缩小、变暗（`scrollTransition`）。
- 回顾页一天最多进几次，可以有这种程度的效果。

### 6. 不改的

- 日记列表滚动、标签栏、日历、网格都保持系统动画，因为最常用。
- 已经做得对、可以当模板的有：
  - 搜索页下拉光圈清除筛选：跟手、过阈值“咔哒”、配触感。
  - 详情页下拉拉伸照片（`StretchyHeader`）。
  - 开屏显影。

## 三、接下来的功能

按价值排序。前四个都不需要付费开发者账号的权限，第二个要先验证。

### 1. 晚间提醒：“今天拍了 8 张，写一句？”

- 本地通知（`UNUserNotificationCenter`），时间可以在设置里改，默认关闭、首次在回顾页问一次。
- 没拍照片、或今天已经写过的日子不提醒。
- 通知可以直接回复（`UNTextInputNotificationAction`）：文字写进今天最佳的一张照片的说明，带写作日期行。
  - “最佳”的选法：优先收藏的照片，其次最后一张。
- 通知回调在后台线程，必须 `nonisolated`，要在 `PhotoKitIntegrationTests` 里真的触发一次（见 CLAUDE.md）。

### 2. 小组件

- 那年今日（主屏中、大尺寸），和“今天还没写”（锁屏圆形，点开直接进编辑器）。
- 数据：照 Watch 的做法，由 App 写一份快照。需要 App Groups 共享。
- **先验证**：免费的个人开发者账号能不能签 App Groups。不行的话，看小组件能不能自己读照片库。

### 3. 快捷指令、Siri、控制中心（App Intents）

- “给最新一张照片写日记”“打开今天的日记”“那年今日”。
- 控制中心和锁屏底部可以放一个“写日记”按钮（`ControlWidget`）。
- 做完后，操作按钮、Spotlight 都能直接调用。

### 4. 从照片 App 分享进来写

- 分享扩展：在照片 App 里选一张照片 → 分享 → 打开相纸编辑器。
- 同样只写说明，不复制照片。

### 5. 一年回顾

- 每年年底，或用了一年时生成一次：全屏、左右翻页，最后能分享成图片。
- 这是全 App 最适合用着色器的地方。照片逐张“显影”，和开屏的显影是同一套语言。

### 要付费开发者账号的

- 手记建议（代码已写好，`JOURNALING_SUGGESTIONS` 开关关着）。
- TestFlight、App Store。
